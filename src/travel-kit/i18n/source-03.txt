<<<HZN0425>>> Start with your own agency
<<<HZN0426>>> This kit supports independent travel advisors and small agencies. Use it for any destination. Choose the language folder that suits the client. The five editions contain the same 40 document pages, not 200 different templates.
<<<HZN0427>>> Unzip the download on a computer. Open Agency_Documents.html in a desktop browser. Enter the agency, client, trip reference, destination, dates and currency at the top. Shared values update across the document pages. Keep the original file as your clean master.
<<<HZN0428>>> Use Worked_Example.html and its eight-page PDF to understand the workflow. Use Operations_Example.xlsx to inspect the calculations, then start real records in Operations_Blank.xlsx. The fictional cities, supplier codes and amounts are teaching data.
<<<HZN0429>>> Edit, save and deliver
<<<HZN0430>>> Click a field to enter text. Choose your agency colour and font in the toolbar. Use the page menu to navigate. Duplicate a daily itinerary or table page when you need more room. A coloured outline warns when text exceeds the page; shorten it or continue on a duplicate page.
<<<HZN0431>>> Save completed copy downloads a new HTML file with your entries, colour, paper size and selection. Reopen that downloaded file to continue. Unsaved edits are not retained when you close the tab. Each language is a separate edition; your client’s answers are not automatically translated.
<<<HZN0432>>> Select only the pages intended for the traveler, then Print selected pages / PDF. The client-page button excludes pages 06, 34 and 38–40, but still review your selection. Choose A4 or Letter, enable background graphics and disable browser headers/footers. Inspect the PDF before sending. Client PDFs are static; calculations remain in the workbook.
<<<HZN0433>>> Run the operations workbook
<<<HZN0434>>> Start in Setup: set one currency and the review date. Changing the currency label does not convert values. The review date controls overdue flags; it does not rebuild historical balances. Use a separate workbook for each currency. Enter real spreadsheet dates, not text.
<<<HZN0435>>> Create a unique trip reference in Trips. Schedule each installment once in Installments. Record each receipt or refund in Receipts using its installment reference; the trip reference is calculated. Pale amber cells are inputs; teal cells contain formulas. Enter 0 where a known amount received is zero. Do not delete formula columns.
